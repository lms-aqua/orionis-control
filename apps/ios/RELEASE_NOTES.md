Orionis Control 0.2.2 delivers major live-camera and recording reliability work plus faster DNS investigations. WebRTC no longer attaches the same remote track twice, waits for UDP TURN before settling for TCP, keeps its Metal renderer stable through SwiftUI updates, detects when a connected peer stops delivering frames, performs bounded fast renegotiation, and then falls back safely instead of showing a frozen stream as live. Stale callbacks from replaced peers are ignored, signalling uses an isolated cache-free session, and duplicated or malformed TURN configuration is normalized. The gateway again prefers the on-demand 0.5-second-keyframe source so packet loss recovers quickly, with the native source retained as an automatic compatibility fallback. HLS segments now stream through the gateway with backpressure instead of being fully buffered, and MPEG-TS plus fMP4 init/part resources are both relayed correctly. Pausing or backgrounding now releases gateway sessions, rapid camera changes are serialized, Wi-Fi/cellular transitions reconnect with the current data policy, audio focus is released when playback stops and restored after system interruptions or route changes, camera health refreshes while visible, camera snapshots are downsampled off the main thread, and an optional playback HUD shows actual decoded FPS, transport, stalls, and reconnects. Recording timelines now use the user's exact local-day bounds, read every coverage page instead of inventing gaps after 200 or 10,000 segments, retain history for offline cameras, keep playback and exports inside real footage, report playback failures, handle byte ranges correctly, bound the server clip cache by memory, and stream exports to disk instead of holding whole videos in iPhone memory. Recording-store measurement is bounded-parallel, distinguishes an unavailable mount from a genuinely empty one, and no longer claims every MediaMTX recording contains audio. DNS query history now loads 250 results by default and can be set to 100, 250, or 500 per page; filtered tabs scan older raw pages instead of falsely stopping at an all-blocked sample. DNS Insights summarizes the loaded sample with outcome mix, classified block rate, top domains and clients, processing performance, one-tap filtering, and a shareable report; watched domains persist across launches. Every blocking iOS UI lane must still pass before the rolling AltStore release is replaced.
