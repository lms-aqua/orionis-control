Orionis Control 1.1.0 stops asking you to be the plumber. Adding a Blink camera used to mean typing two container addresses before the form would accept anything — and the addresses it suggested named a container that does not exist on most installs, so the first thing you met was a screen that refused to save. Blink now asks for an email and a password. Everything underneath is Orionis's problem: when a source needs a helper service, the app offers to start one, the server brings it up from a template that ships with the release, and the connection fills in its own addresses when it is ready. The verification code Blink sends arrives in the app, where you can type it, instead of in a terminal on the server.

The same applies to Wyze, and to any RTSP source that needs a discovery service. Sources that are already systems you own — Frigate, UniFi Protect, a Tapo camera, Nest — are unchanged: you point at them, because there is nothing to start. Where a helper is optional the fields are still there, tucked into an advanced section rather than blocking the form, and a connection saved without one signs in and says live view needs a bridge rather than failing in a way that names software you have never heard of.

This release also fixes a bug that reached well outside the app. Opening a recording could silence the microphone for whatever else was running — a call, a screen share — and it stayed silenced until Orionis was force-quit. The app was claiming the device's audio exclusively and never giving it back: the live viewer set an output-only audio mode and left it set, the recordings player then activated it without ever releasing it, and nothing put things back. Camera audio now mixes with everything else on the phone instead of taking it over, and the session is handed back the moment playback stops, so other apps are told they can resume.

One thing worth knowing: that audio fix is verified by tests and by inspection, not on hardware. If a call or a screen share still loses its microphone when you open a recording, that is worth reporting rather than working around.
