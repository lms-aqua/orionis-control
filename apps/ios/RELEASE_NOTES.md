Orionis Control 0.2.0 is a broad reliability and usability release. AdGuard query activity now correctly distinguishes allowed requests from blocked requests, including modern AdGuard reason and rule formats, with regression coverage for the normalization bug. Camera favourites and ordering report save failures instead of silently losing changes, and failed favourite writes roll back cleanly. Recording playback advances across window boundaries without replaying the final frame, WebRTC reconnect timeouts no longer leak into newer sessions, and camera details preserve valid state when secondary refreshes fail. System, infrastructure, storage, device, event, recording, and authentication flows now reject stale asynchronous results, preserve previously valid secondary data, surface pagination and deep-link failures, and keep unsaved notification edits honest while a save is in flight.
